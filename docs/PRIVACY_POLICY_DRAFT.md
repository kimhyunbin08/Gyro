## 1. 처리 목적 및 항목

| 처리 목적 | 처리 항목(현행 구현 기준) | 보유·처리 방식 |
|---|---|---|
| 익명 서비스 탐색 및 통계 | 서비스 ID, 선택·미선택, 미리보기·문서 클릭, 연결 결과 등 이벤트 메타데이터 | API 프로세스 메모리에 최근 최대 5,000건을 보유하며 재시작 시 소멸. 빌더 대시보드용 서비스별 집계 수치는 PostgreSQL에 저장되고 현재 자동 만료 정책이 없음 |
| 선택적 이메일 리드 | 이메일 주소, 소식 수신 동의 여부 | 현재 API 프로세스 메모리에 저장되며 영속 DB 저장 또는 이메일 발송은 구현되어 있지 않음. 재시작 시 소멸 |
| 빌더 로그인 | 빌더 이메일, 매직링크 토큰 해시, 세션 토큰 해시, 만료 시각, 계정 상태 및 프로그램 참가 확인 여부 | PostgreSQL에 저장. 원문 매직링크·세션 토큰은 저장하지 않음. 매직링크는 15분, 세션은 7일 만료 |
| 빌더 제출·소유권 관리 | 서비스 제출 내용, 공식 링크, 태그, 소유권 확인 자료, 처리 상태 | PostgreSQL에 저장. 현재 자동 삭제·보유 기간 정책은 정해져 있지 않음 |
| 공개 댓글 및 신고·운영 | 선택 닉네임, 댓글 본문, 생성 시각, 신고 수, 공개 상태, 운영자 조치 이력 | 댓글·운영 감사 기록은 PostgreSQL에 저장. 현재 자동 삭제·보유 기간 정책은 정해져 있지 않음 |
| 요청 제한·남용 방지 | 요청 IP 또는 프록시가 제공한 클라이언트 주소, 이메일을 키로 한 제한 상태 | API 프로세스 메모리의 일시적 rate-limit 상태에 사용. 애플리케이션 DB에 이 제한 키를 영속 저장하지 않음. 호스팅·프록시·보안 로그의 IP 처리는 별도 확인 필요 |
| 대화형 AI 추천 | 사용자가 입력한 문제 설명, 기술 스택/도구, 선택적으로 공개 GitHub 저장소 URL 및 공개 정보 | Gyro 애플리케이션이 대화 내용을 영구 저장하지 않도록 설계됨. 요청 처리를 위해 GitHub Copilot SDK 및 선택 모델 제공자에게 전송됨. 해당 제공자의 처리·보유 조건은 확인 후 기재해야 함 |

위 항목은 현재 코드의 저장 경로를 설명하며, 실제 개인정보 해당 여부나 법적 처리 근거에 대한 판단이 아니다.
제공받는 정보에 개인정보가 포함되지 않도록 이용자에게 안내하고, 개인정보 포함 시 처리 방침을 별도로
확정해야 한다.

## 2. 처리 및 보유 기간

현재 구현에는 이메일 리드, 공개 댓글, 제출 자료, 소유권 증빙, 빌더 계정, 집계 지표 및 관리자 감사 기록의
종료·삭제 일정을 자동으로 적용하는 보유 기간 정책이 없다. 따라서 위 표의 미확정 영속 자료는 공개 출시 전에
각 목적별 보유 기간, 이용 종료 후 삭제 시점, 분쟁·신고·법적 보존 예외 및 백업 삭제 주기를 정해야 한다.

코드상 매직링크는 15분, 빌더 세션은 7일 만료된다. 만료 토큰/세션 정리는 새 로그인 요청 또는 세션 작업
중 일부 수행되며, 별도 주기적 정리 작업은 확인되지 않았다. 익명 이벤트는 API 프로세스당 5,000건 상한을
두지만 프로세스 재시작 시 사라진다. 서비스별 빌더 집계는 별도 DB에 누적되어 재시작 후에도 유지된다.

**공개 전 확정할 항목:** 데이터 유형별 기간, 이용 목적 달성·탈퇴·삭제 요청 시 처리, 법령상 보존 의무,
백업·로그·제3자 제공자 측 보유 기간.

## 3. 제3자 제공, 처리 위탁 및 국외 이전

다음은 현재 기술 설계에서 예상되는 제공자 범주이며, 계약 관계·리전·처리 위치·재위탁자·보유 기간과 법적
고지/동의 요건을 실제 배포 환경과 계약으로 확인한 뒤 확정해야 한다.

| 제공자/범주 | 예상 데이터 | 목적 | 확인할 사항 |
|---|---|---|---|
| Azure 호스팅 및 PostgreSQL 운영자 | 요청·계정·제출·댓글·집계 데이터 | API 및 영속 저장 운영 | 리전, 로그, 재위탁자, 삭제·백업, 국외 이전 여부 |
| Azure Communication Services Email | 빌더 이메일 주소와 로그인 링크 | 빌더 매직링크 이메일 발송 | 발신 서비스 리전, 메시지 처리·로그 보유 및 국외 이전 |
| GitHub Copilot SDK 및 선택 모델 제공자 | 동의한 AI 대화 입력, 선택한 공개 저장소의 URL·공개 설명 정보 | 카탈로그 추천 생성 | 서비스 운영 목적 사용 허용 여부, 보유/학습 정책, 처리 국가, 계약·동의 필요 여부 |
| 웹 호스팅/CDN/보안 프록시 | 접속·네트워크 메타데이터 및 운영 로그 | 서비스 제공·보안·오류 진단 | 실제 공급자, 로그 항목, 보유 기간, 국외 이전 |

개인정보 처리자와 바이브벤처/교육기관 간의 역할(독립·공동 처리자 또는 수탁 관계)은 **[기관·법률 검토
후 기재]**한다. 확인되지 않은 제공자·국가·계약을 확정된 사실처럼 게시하지 않는다.

## 4. 이용자 권리와 요청 방법

정보주체의 열람·정정·삭제·처리정지 등 권리 행사 범위, 대리인 요청, 본인 확인 절차 및 처리 기한은
**[법률 검토 후 확정]**한다. 익명 댓글은 작성자 식별 정보를 받지 않으므로 작성자 확인과 삭제 요청을
처리할 방식을 공개 전 마련해야 한다. 요청 접수처는 **[공식 개인정보 문의 연락처]**다.

## 5. 쿠키·브라우저 저장

빌더 로그인에는 7일 만료의 HttpOnly 세션 쿠키가 사용된다. 프로덕션 환경에서 Secure 및 SameSite=None
속성을 적용하도록 구현되어 있다. 테마 선택은 브라우저 로컬 설정으로 유지하며 서버 계정이나 추천 개인화에
사용하지 않는다. 실제 웹 분석 도구, 쿠키, CDN 추적 기능이 추가되는 경우 본 방침과 동의 화면을 갱신한다.

## 6. 개인정보 보호 조치

현재 코드에는 매직링크·세션 원문 대신 해시 저장, HttpOnly 인증 쿠키, Origin 제한, API 입력 검증,
요청 제한, 운영자 인증 및 관리자 변경 감사 기록이 포함되어 있다. 이는 완전한 보안을 보장하지 않는다.
운영 환경의 전송·저장 암호화, 접근권한, secret 관리, 백업, 로그 마스킹, 취약점 대응 및 사고 통지 절차는
배포 전에 검증하고 담당자를 지정해야 한다.

## 7. 미성년자 및 공개 게시물

바이브벤처 참가자와 Gyro 이용자에 미성년자가 포함될 수 있는지, 법정대리인 동의 또는 연령 제한이 필요한지,
학교·교육기관이 수행하는 확인 절차를 Gyro가 신뢰할 수 있는지는 **[기관·법률 검토 후 확정]**한다.
공개 댓글에 본인 또는 제3자의 개인정보가 포함될 수 있으므로 신고·숨김·삭제·긴급 대응 절차와 연락처를
마련하기 전에는 댓글 기능을 공개 활성화하지 않는다.
