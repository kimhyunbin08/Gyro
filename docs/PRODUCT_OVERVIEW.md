# Gyro 제품 개요

> 이 문서는 현재 제품 범위와 아이디어를 빠르게 이해하기 위한 요약이다. 상세 요구사항과 인수 조건은
> [`prd.md`](../prd.md), 구현/API 설계는 [`trd.md`](../trd.md), 미승격 아이디어는
> [`ideation.md`](../ideation.md)를 기준으로 한다.

## 제품 한 줄 설명

Gyro는 **바이브벤처 프로그램에서 만들어진 서비스를 발견하고, 직접 살펴보고, 반응을 남길 수 있게 돕는
대화형 서비스 발견 플랫폼**이다. 발견자는 가입하지 않고 서비스를 둘러보며, 제작자는 별도 검증된 빌더
포털에서 서비스 정보를 제출·수정하고 익명 집계 피드백을 확인한다.

## 해결하려는 문제

- 이용자는 자신이 해결하려는 문제에 맞는 프로그램 제작 서비스를 한곳에서 비교하고 발견하기 어렵다.
- 제작자는 만든 서비스를 적절한 이용자에게 소개하고, 실제 관심·체험 신호를 구조화해 확인하기 어렵다.
- 공개 카탈로그와 제작자 권한을 무단 자동 수집이나 자동 공개에 의존하지 않고 관리할 필요가 있다.

## 이용자와 핵심 흐름

### 서비스 발견자

로그인 없이 사전 질문(사용자 유형과 관심사)에 답하고 카드를 살펴본 뒤, 관심 서비스 결과와 공식 링크를
확인한다. 서비스 탐색은 홈 대화형 추천, 주제별 탐색, 작업으로 찾기, 랭킹 및 결과 화면으로 이어진다.
이메일 저장은 선택 사항이며, 출시 소식 수신은 별도 선택 동의다.

### 바이브벤처 제작자

이메일 매직링크로 빌더 포털에 접속한다. 운영자가 바이브벤처 프로그램 참여와 기존 서비스 소유권을
확인한다. 참여 확인과 계정 승인이 모두 끝난 제작자는 서비스 제출·수정안을 검수 대기열에 올리고, 승인된
서비스의 집계 대시보드를 확인한다. 제출이나 수정은 운영자 승인 전에는 공개되지 않는다.

### 공개 댓글

서비스 상세 화면에는 이메일 없이 익명 또는 선택 닉네임으로 공개 댓글을 남길 수 있다. 댓글은 즉시
공개되며 신고할 수 있고 운영자는 숨김·복구·삭제할 수 있다. 이 동작은 공개 출시 전 담당 기관·법률
검토로 변경될 수 있다.

## 카탈로그와 신뢰 원칙

- 노출 대상은 바이브벤처 프로그램 제작 서비스로 제한한다. 현재 정적 카탈로그는 제품 범위상 적격으로
  간주하지만, 각 항목의 프로그램 출처와 공개 권한은 출시 전 담당자 확인이 필요하다.
- 공식 API·허용된 공개 자료·공식 사이트/문서·공개 저장소 등 합법적 경로에서 후보를 확인하고, 출처와
  공개 권한을 사람이 검토한 뒤 카탈로그에 등록한다. 무단 크롤링이나 검수 없는 자동 공개는 하지 않는다.
- 카탈로그의 라이브 헬스체크, 공식 링크 중복 제거, 설명 가능한 추천 이유와 빈 결과 폴백을 유지한다.
- 연결 안내는 iframe 자동 실행·설치가 아니라 안내 패널을 제공한다. 검증 수준은 사람의 확인 기록으로만
  부여한다.

## AI 기능과 데이터 경계

홈의 대화형 추천은 사용자가 직접 입력한 문제·기술 스택/도구와 선택적으로 제공한 공개 GitHub 저장소의
공개 정보를 이용해 카탈로그 안의 후보를 추천한다. 요청 내용은 Gyro 서버의 영속 저장소나 퍼널 이벤트에
저장하지 않는 것이 요구사항이다. 사용자는 입력을 GitHub Copilot SDK와 선택 모델 제공자에게 전송하는 데
동의해야 하며, 제공자 측 처리 조건은 공개 전에 확인해야 한다.

AI 간 교차검증은 문서에 정의된 기능과 확장안을 구현할 때 요구사항 정합성·구현 오류·배포 준비 상태를
독립적으로 확인하는 개발 검증 절차다. 사용자 대상 AI 추천 기능이나 향후 제품 확장 아이디어를 뜻하지 않는다.

## 현재 MVP와 미승격 아이디어

**현재 MVP 범위:** 로그인 없는 발견, VibeVenture 한정 카탈로그, 헬스체크와 중복 제거, 추천 이유, 익명
퍼널·인기 랭킹·마이크로 피드백, 선택 이메일 리드, 세션 내 대화형 AI 추천, 검증된 빌더 포털, 검수형
서비스 제출·수정, 소유 서비스 집계 대시보드, 익명 공개 댓글과 운영자 신고 처리.

**아직 구현/승격되지 않은 아이디어:** A/B 카드 실험, 유형별 랭킹, 탐색 비율,
유료 개선 리포트, 자동 실행·설치, 사용자 계정과 장기 기억, 비공개 저장소 접근, 무단 크롤링 및 검수 없는
카탈로그 공개.

## 공개 전제

제품 범위가 정해졌다고 해서 공개 준비가 완료된 것은 아니다. PostgreSQL·메일·관리자 secret 구성,
프로그램 참가 및 저작물 공개 권한 확인, 개인정보 처리 역할·보존 기간·미성년자 정책·댓글 대응 절차
확정과 법률 검토가 끝나기 전에는 빌더/댓글 기능을 공개 활성화하지 않는다. 초안은
[`TERMS_DRAFT.md`](./TERMS_DRAFT.md) 및 [`PRIVACY_POLICY_DRAFT.md`](./PRIVACY_POLICY_DRAFT.md)를
참고한다.
