정식 운영 전 초안
이 문서는 서비스의 데이터 흐름을 설명하는 준비 문서이며, 개인정보 처리방침으로 게시할 수 있는 최종본이 아닙니다. 운영자·연락처·실제 처리업체/국가·보유기간·법률 검토가 완료되기 전까지 창업가 가입과 제출 기능은 비활성화됩니다.

처리 주체와 문의

운영 주체와 개인정보 보호 문의 연락처는 정식 공개 전에 실제 운영자 정보로 이곳에 표시되어야 합니다. 현재는 확정되지 않았습니다.

서비스 발견 이용

서비스 탐색은 로그인 없이 이용할 수 있습니다. 탐색 과정에서 선택된 서비스와 익명 세션 식별자를 포함한 이벤트가 추천·랭킹·퍼널 통계 목적으로 처리될 수 있습니다. 초기 구현의 이벤트와 이메일 리드는 인메모리 저장소를 사용하며, 서버 재시작 시 사라질 수 있습니다.

대화형 AI 추천을 선택하면 사용자가 직접 입력한 문제/기술 정보와 선택한 공개 GitHub 저장소의 공개 정보가 응답 생성을 위해 GitHub Copilot 및 선택된 모델 제공자에게 전송됩니다. 비밀번호, API 키, 비공개 저장소 내용은 입력하지 마세요. 대화와 README는 Gyro의 영속 저장소나 퍼널 이벤트로 저장하지 않도록 설계되어 있습니다. 실제 제공자, 처리 국가, 보유 조건은 운영 전 확정해 공지해야 합니다.

창업가 계정 및 서비스 제출

활성화될 경우 창업가의 이메일, 표시 이름, 연령 기준 자가 확인, 약관/개인정보 고지 버전 동의 기록, 로그인 세션, 제출한 서비스 설명·공식 URL·문서 URL·작업 태그, 검수 결과가 계정·검수 운영에 사용됩니다. GitHub 로그인은 계정 식별을 위해 GitHub 사용자 ID, 검증된 이메일 및 공개 이름을 확인하고 OAuth access token은 저장하지 않습니다. 이메일 로그인은 SMTP를 통해 일회용 링크를 발송합니다.

제출물은 운영자 승인 전 공개되지 않습니다. 승인된 제출물은 Gyro 카탈로그에 소개될 수 있습니다. 처리 위탁자와 저장 지역, 백업·보유·삭제 시점은 실제 클라우드/메일 공급자와 계약을 확인한 후 구체적으로 고지해야 합니다.

연령 및 권리 행사

일반 발견 이용자에게 나이를 묻지 않습니다. 창업가 계정은 만 14세 이상 자가 확인을 전제로 하며, 생년월일은 수집하지 않습니다. 보호자 동의를 모든 미성년 계정의 가입 조건으로 요구하지 않으며, 법률상 필요한 구체적인 개인정보 처리 또는 권리 부여는 해당 단계에 별도로 적용해야 합니다.

열람·정정·삭제 및 처리정지 요청 방법, 실제 보유 기간, 파기 절차는 운영자 연락처와 저장소 설정을 확정한 뒤 최종 방침에 기재해야 합니다. 계정 삭제 기능은 계정 및 연결된 제출 데이터를 제거하도록 설계되어 있습니다.

서비스 활성화 조건

이 초안만으로 법적 적합성 또는 처리 동의를 주장하지 않습니다. 실제 운영자 정보, 데이터베이스/메일/AI 처리자와 국가, 보유 기간, 국외 이전과 위탁 관계를 확인하고 국내 법률 전문가 검토를 완료한 다음에만 정식 방침을 게시할 수 있습니다.
