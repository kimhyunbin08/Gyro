정식 운영 전 초안
이 문서는 서비스의 데이터 흐름을 설명하는 준비 문서이며, 개인정보 처리방침으로 게시할 수 있는 최종본이 아닙니다. 운영자·연락처·실제 처리업체/국가·보유기간·법률 검토가 완료되기 전까지 창업가 가입과 제출 기능은 비활성화됩니다.

처리 주체와 문의

운영 주체와 개인정보 보호 문의 연락처는 정식 공개 전에 실제 운영자 정보로 이곳에 표시되어야 합니다. 현재는 확정되지 않았습니다.

서비스 발견 이용

서비스 탐색은 로그인 없이 이용할 수 있습니다. 탐색 과정에서 선택된 서비스와 익명 세션 식별자를 포함한 이벤트가 추천·랭킹·퍼널 통계 목적으로 처리될 수 있습니다. 초기 구현의 이벤트와 이메일 리드는 인메모리 저장소를 사용하며, 서버 재시작 시 사라질 수 있습니다.

대화형 AI 추천을 선택하면 사용자가 직접 입력한 문제/기술 정보와 선택한 공개 GitHub 저장소의 공개 정보가 응답 생성을 위해 GitHub Copilot 및 선택된 모델 제공자에게 전송됩니다. 비밀번호, API 키, 비공개 저장소 내용은 입력하지 마세요. 대화와 README는 Gyro의 영속 저장소나 퍼널 이벤트로 저장하지 않도록 설계되어 있습니다. 실제 제공자, 처리 국가, 보유 조건은 운영 전 확정해 공지해야 합니다.

창업가 계정 및 서비스 제출

활성화될 경우 창업가의 이메일, 표시 이름, 연령 기준 자가 확인, 약관/개인정보 고지 버전 동의 기록, 로그인 세션, 제출한 서비스 설명·공식 URL·문서 URL·작업 태그, 검수 결과가 계정·검수 운영에 사용됩니다. GitHub 로그인은 계정 식별을 위해 GitHub 사용자 ID, 검증된 이메일 및 공개 이름을 확인하고 OAuth access token은 저장하지 않습니다. 이메일 로그인은 SMTP를 통해 일회용 링크를 발송합니다.

제출물은 운영자 승인 전 공개되지 않습니다. 승인된 제출물은 Gyro 카탈로그에 소개될 수 있습니다. 처리 위탁자와 저장 지역, 백업·보유·삭제 시점은 실제 클라우드/메일 공급자와 계약을 확인한 후 구체적으로 고지해야 합니다.

처리 목적·항목·근거 확정표

아래는 현재 구현에 따른 초안입니다. 각 처리의 법적 근거와 필요한 동의는 실제 운영 조건을 확인해 확정해야 합니다. 방침 열람 확인이나 약관 동의를 모든 개인정보 처리의 포괄 동의로 사용하지 않습니다.

  • 계정 인증·관리: 이메일, 표시명, GitHub 식별자, 연령 기준 확인, 정책 버전 및 확인 시각. 인증·계정 제공에 필요한 범위와 처리 근거를 확정합니다.
  • 인증 보호: 세션·CSRF·일회용 인증값의 해시와 만료 시각, 발송 요청 제한용 IP 및 이메일 해시. 원문 인증값과 OAuth access token은 DB에 저장하지 않습니다.
  • 제출·검수: 서비스 설명과 링크, 작업 태그, 권한 진술, 수정 이력, 검수 사유 및 검수자 이메일. 제출 내용에는 불필요한 개인정보·비밀을 넣지 마세요. 승인된 서비스 정보만 공개하고 계정 이메일·내부 권한 진술·검수 기록은 공개 카탈로그에 포함하지 않습니다.
  • 발견·피드백: 무작위 세션 식별자, 선택·클릭·이유 태그, 선택적 평점·의견. 의견에 개인정보를 쓰지 마세요. 식별자를 사용한다고 법률상 익명정보임을 보장하지 않습니다.
  • 선택적 결과 이메일: 입력 이메일을 결과 저장용으로 처리하며 소식 수신 선택과 구분합니다. 현재는 이메일 주소 중복 방지만 구현되어 실제 결과 메일·마케팅 메일을 발송하지 않습니다.

인증 유효기간과 실제 파기

이메일 로그인 링크는 15분·1회 사용, OAuth state는 10분, 로그인 세션은 7일 동안 유효합니다. 이는 사용 가능 시간이며 물리적 파기 기한을 뜻하지 않습니다. 만료된 인증 행의 정리는 현재 후속 인증 요청 때 수행되므로, 운영 전 별도 정리 주기와 모니터링을 확정해야 합니다.

계정 삭제 시 계정과 연결된 인증 identity·세션·동의 기록·제출물·수정 이력·검수 기록은 DB에서 연쇄 삭제됩니다. 계정 외부에 저장된 로그인 링크·OAuth state, 백업·메일 공급자 기록은 별도 정리 대상입니다. 운영 로그·백업의 보유기간, 삭제 주기·방법, 복원 시 삭제 재적용 절차와 법령상 보존 예외의 근거·항목·기간은 아직 확정되지 않았습니다.

쿠키·로컬 설정·외부 요청

창업가 로그인은 세션 쿠키와 GitHub 로그인 확인용 state 쿠키를 사용합니다. 브라우저에서 쿠키를 차단하거나 삭제할 수 있으나 로그인 유지·인증이 제한됩니다. 화면 테마는 브라우저 localStorage에 저장하며 브라우저 사이트 데이터 삭제로 초기화할 수 있습니다. 발견 이벤트 식별자는 페이지 메모리에만 유지하고 계정과 연결하지 않습니다.

웹 폰트 로딩을 위해 Google Fonts 서버에 브라우저 요청이 발생하며 IP·브라우저 요청 정보가 전달될 수 있습니다. 호스팅·접속 로그와 이 요청도 실제 개인정보 처리 현황에 포함해 검토해야 합니다.

외부 처리자·국외 이전 확정 항목

DB·웹/API 호스팅, SMTP, GitHub OAuth, GitHub Copilot·실제 선택 모델 제공자, 외부 폰트별로 업체 법인명·연락처·역할(위탁/제3자 제공 등), 처리 국가·재위탁, 이전 항목·시기·방법·목적·보유기간, 적용 근거, 거부 방법과 효과를 확정해야 합니다. Azure를 사용하거나 한국 리전을 선택했다는 사실만으로 모든 데이터의 국내 처리 또는 국외 이전 적법성을 보장하지 않습니다.

연령 및 권리 행사

일반 발견 이용자에게 나이를 묻지 않습니다. 창업가 계정은 만 14세 이상 자가 확인을 전제로 하며, 생년월일은 수집하지 않습니다. 보호자 동의를 모든 미성년 계정의 가입 조건으로 요구하지 않으며, 법률상 필요한 구체적인 개인정보 처리 또는 권리 부여는 해당 단계에 별도로 적용해야 합니다.

열람·정정·삭제 및 처리정지 요청 방법, 실제 보유 기간, 파기 절차는 운영자 연락처와 저장소 설정을 확정한 뒤 최종 방침에 기재해야 합니다. 계정 삭제 기능은 계정 및 연결된 제출 데이터를 제거하도록 설계되어 있습니다.

정식 방침에는 개인정보 보호책임자 또는 고충 처리 담당 연락처, 본인·대리인 확인 방법, 요청 처리 절차와 법정 제한 사유, 동의 철회 방법, 안전성 확보 조치, 권익 침해 구제 경로, 시행일·변경 이력도 포함해야 합니다. 현재 미정인 문의처나 처리 기한을 실제 운영 약속으로 표시하지 않습니다.
