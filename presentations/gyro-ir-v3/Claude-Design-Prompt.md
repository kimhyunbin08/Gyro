## 요청

Gyro의 5분 투자 피칭 덱 13장을 디자인해 줘.
- 청중: 대구 IT 기업 대표 심사위원
- 형식: 피칭 5분 + 질의 5분

이 덱은 **자료 제출용이 아니라 무대에서 말과 함께 넘기는 피칭용**이다. 설명은 발표자가 말로 하고, 슬라이드에는 아래 셋 중 하나만 크게 둔다.
- 숫자 하나
- 문장 하나
- 실제 제품 화면 하나

슬라이드 문구와 내용은 아래 표 그대로 쓰고, 새 수치나 문구를 만들지 마.

## 디자인 방향

- **톤:** Claude 브랜드의 주황·갈색·크림. **구성:** YC·a16z 데모데이 덱처럼 단순하게.
  - YC·a16z 로고, 이름, 승인을 암시하는 요소는 넣지 마.
- **색**
  - 배경: `#FAF9F5`(Paper), `#F0EEE6`(Paper-2), `#141413`(Ink, 강조 슬라이드)
  - 강조: `#C15F3C`(Clay, 밝은 배경 위), `#D97757`(Coral, 어두운 배경 위)
  - 본문 보조: `#5E5D59`, 출처: `#73726C`
- **서체:** 제목·숫자는 Noto Serif KR 700–900, 본문은 Noto Sans KR
- **크기:** 대형 숫자 300–440px, 제목 88–96px, 보조 36–48px, 출처 18px (1920×1080 기준)
- **레이아웃:** 여백이 위계를 만든다. 제목은 위나 가운데에 크게, 요소는 최소로.
- **AI 티 줄이기:** 아래 요소를 넣지 마.
  - 섹션 번호 아이브로(“01 · PROBLEM”)
  - 하단 면책 문구 띠
  - 3열 카드 반복
  - 장식 아이콘, 그라데이션 블롭
  - 이모지
  - 스톡 사진
- **출처:** 해당 숫자나 인용 바로 아래에 18px로 작게 단다. 페이지 하단 각주 띠로 만들지 마.

## 이미지 규칙 (중요)

- 제품 화면은 **첨부한 `captures/` PNG만** 쓴다. 제품 UI를 그리거나 합성하거나 다시 만들지 마.
- 캡처는 3200×1800(16:9)이다. 자르기는 해도 되지만 화면 내용을 바꾸지 마.
- 캡처는 기기 프레임 없이 얇은 테두리(1px `#E8E6DC`)와 큰 라운드(24px), 옅은 그림자로 올린다.
- 인물 사진, 로고, 외부 이미지는 쓰지 않는다.
- 차트는 첨부 원고의 수치만으로 그린다.

## 사실 경계 (반드시 지킬 것)

- 고객 반응, 매출, 계약, 이용자 수는 **없다**. 이를 암시하는 숫자, 그래프, 후기를 만들지 마.
- 1조 원은 **목표에서 역산한 값**이다. 예측이나 실적처럼 보이는 그래프(하키스틱 등)로 그리지 마.
- 13장의 4주·20개·100명은 **제안 규모**다. 달성한 실적처럼 쓰지 마.
- 84%는 “한 분기” 기준이다. “전년 대비”라고 쓰지 마.
- 인용문은 원고 그대로 쓰고, 출처를 반드시 함께 단다.
